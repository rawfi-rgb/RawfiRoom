# RawfiRoom — 온라인 작곡·기타 레슨 & 합주 스튜디오

링크 하나로 초대하는 1:1 레슨룸입니다. (Zoom/Meet 방식)

## 모드 (4가지)
- **선생님 모드**: 레슨룸을 만들고 `선생님 도구`로 레슨생 화면 요청, 마이크 끄기, 악보 페이지 고정, 필기 허용, 가사 저장 허용을 관리.
- **레슨생 모드**: 초대 링크로 입장. `손들기`, 자기 필기만 지우기.
- **합주 모드**: 모두 같은 권한. 저지연 오디오(10ms 프레임), 악기 원음, 영상 최소화, 최소 출력 버퍼가 자동 적용. 메트로놈과 마디 싱크로 합주.
- **미팅 모드**: 모두 같은 권한으로 화면 공유, 가사노트, 자료함을 함께 작업. 대화용 에코 제거 켬.
- 모드는 방 전체에 적용되고, 상단 모드 배지로 바꿀 수 있어요. 레슨 중에는 선생님만 바꿀 수 있어요.

## 수업 녹화
상단 `녹화` 버튼:
- **영상 + 소리**: MP4/WebM, 1280×720, 영상 중심 또는 악보 + 영상 합성.
- **소리만 무손실 WAV**: 내 마이크와 DAW 원음 + 상대 소리 + 내장 악기를 함께 담음.

녹화 중에는 모든 참가자에게 REC 표시가 보여요. 끝나면 다운로드하거나 자료함에 올릴 수 있어요.

| 탭 | 기능 |
|---|---|
| 영상 무대 | 카메라·마이크, 화면 공유, 선생님이 레슨생 화면 공유 요청, 탭 크게 보기(영상은 작은 창) |
| 악보 | PDF·이미지·빈 오선지 → 양쪽 필기 실시간 공유, Apple Pencil 지원, 함께 페이지 넘기기, 악보함(폴더) |
| 가사노트 | 폴더별 노트, 동시 편집(한글 입력 안전), 선생님이 **레슨생 저장 허용** 토글 → txt/md/복사/공유/PDF |
| 합주 | 지연 측정·등급, 저지연 합주 모드(Opus 10ms·무대기 MIDI), 시계 동기 메트로놈, 마디 싱크 합주(NINJAM 방식) |
| 악기·MIDI | 내장 가상악기 8종, Web MIDI(Logic Pro IAC), 연주 공유 방식, MIDI 녹음 → .mid (참가자별 트랙) |
| 자료함 | Logic 바운스(WAV/AIFF)·MIDI·악보 원본을 **무손실**로 주고받기 (최대 2GB) |
| 일정 | 다음 레슨 제안 → 수락 → Apple/Google/Outlook 캘린더 저장 (30분 전 알림, 입장 링크 포함) |
| 설정 | 마이크·DAW 입력·카메라·출력 장치, 전송 음질, 실시간 지연/손실 통계, Logic 연결 가이드 |
| 하단 독 | 터치 건반 / 기타 지판 — 내 연주(파랑)·상대 연주(주황) 실시간 표시 |

## 실행

```bash
npm install
npm start          # http://localhost:8787
```

## 배포 (GitHub → Render 자동 배포)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/rawfi-rgb/RawfiRoom)

- `main` 브랜치에 푸시할 때마다 GitHub Actions가 빌드 검사(문법 검사 + 서버 실행 확인)를 하고, Render가 자동으로 새 버전을 배포해요 (`render.yaml`).
- 카메라·마이크·MIDI는 HTTPS에서만 동작해요. Render는 HTTPS를 자동으로 붙여줘요. GitHub Pages는 WebSocket 서버를 실행할 수 없어서 사용하지 않아요.
- 무료 플랜은 15분 동안 아무도 없으면 잠들고(첫 접속에 30~60초), 재배포하면 서버 저장 기록이 사라져요. 노트·필기·녹화를 계속 보관하려면 Starter 플랜 + Disk를 붙이고 `DATA_DIR`을 디스크 경로로 지정하세요.
- 환경 변수: `PORT`(자동), `DATA_DIR`, `TURN_URL`·`TURN_USER`·`TURN_PASS`(회사·학교망처럼 직접 연결이 막힌 곳용 중계 서버).

## 로컬 개발 메모

iCloud Drive에 보관 중이라 `node_modules`는 `node_modules.nosync`(iCloud 동기화 제외)로 연결돼 있어요. 새 Mac에서는 `npm install` 후 같은 방식으로 연결하면 돼요.

## 지연·음질에 대해 솔직하게

- 오디오는 **P2P WebRTC + Opus 48kHz 스테레오 최대 510kbps**, 에코/잡음 처리 끔, 지터 버퍼 최소화. 같은 나라 안이면 보통 단방향 30~60ms 수준입니다. 인터넷 특성상 지연 "0"은 물리적으로 불가능하므로, 설정 탭에서 실제 지연을 확인할 수 있게 했습니다.
- 실시간 스트림은 Opus(지각적으로 투명한 수준)이고, **완전한 무손실은 자료함 원본 전송**으로 보장합니다 (업로드/다운로드 비트 단위 동일 확인).
- 건반 연주는 오디오가 아니라 **MIDI만 전송**해서 각자 기기에서 소리를 내므로 음질 손실이 없고 지연이 가장 짧습니다.

## iPad 참고

Safari 제한으로 **Web MIDI와 화면 공유는 iPad에서 불가**합니다 (Mac/PC Chrome·Edge 사용). 영상·음성, 터치 건반·지판, 악보 필기(Pencil), 가사노트, 일정, 자료함은 모두 동작합니다. Safari → 공유 → "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.
